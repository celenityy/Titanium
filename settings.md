# Recommended Settings

This guide details additional recommended settings *(from [`chrome://settings`](chrome://settings))* that can't be configured from policies.

## Autofill and passwords

Password Manager -> Settings -> **Sign in automatically** -> ❌

Payment methods -> **Save security codes** -> ❌ *(You'll need to temporarily enable `Save and fill payment methods to configure this setting. Ensure you disable it again after)*

Payment methods -> **Card benefits** -> ❌ *(You'll need to temporarily enable `Save and fill payment methods to configure this setting. Ensure you disable it again after)*

## Privacy and security

Third-party cookies -> Advanced -> **Send a "Do Not Track" request with your browsing traffic** -> ✅

## Site settings

### Permissions

Embedded content -> Default behavior -> **Sites are blocked from asking you to use information they've saved about you** -> ✅

#### Additional permissions

Background sync -> Default behavior -> **Don't allow closed sites to finish sending or receiving data** -> ✅

MIDI device control & reprogram -> Default behavior -> **Don't allow sites to control and reprogram your MIDI devices** -> ✅

Payment handlers -> Default behavior -> **Don't allow sites to install payment handlers** -> ✅

Augmented reality -> Default behavior -> **Do not allow sites to create a 3D map of your surroundings or track camera position** -> ✅

Virtual reality -> Default behavior -> **Don't allow sites to use virtual reality devices or data** -> ✅

Your device use -> Default behavior -> **Don't allow sites to know when you're actively using your device** -> ✅

Scrolling and zooming shared tabs -> Default behavior -> **Don't allow sites to scroll and zoom shared tabs** -> ✅

### Content -> Additional content settings

Protected content IDs -> **Don't allow sites to play protected content** -> ✅

Third-party sign-in -> **Block sign-in prompts from identity services** -> ✅

Auto-verify -> **Auto-verify** -> ❌


**Automatically remove permissions from unused sites** -> ✅
